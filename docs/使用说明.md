# Echo Point Nova 单人修改器 1.0

直接运行 `EchoPointNovaTrainer.exe`。主程序为单个文件，无需安装；使用 Windows 的 .NET Framework 与原生 WinForms 界面。

本版适配 **游戏 3.23 / Steam build 22752386 / Windows x64**。默认游戏目录为 `L:\SteamLibrary\steamapps\common\Greylock`。游戏更新后，可执行文件指纹不匹配时会拒绝连接。

## 开始使用

1. 在 Steam 启动游戏，载入单人关卡，也可以点击修改器右上角的“启动游戏”。
2. 打开修改器，等待显示“已连接 · 单人关卡”。主菜单下显示等待状态，功能控件暂不可用。
3. 开关类功能直接打开；数值类功能输入数值后点击“应用”；一次性操作点击“执行”。
4. 需要撤销时关闭开关、点击该行“还原”，或按 **F12 全部还原**。正常关闭修改器也会恢复持续修改的属性。

“还原”恢复的是启用该项前读取到的值，能保留角色自身的升级效果。生命、法力、肾上腺素、弹药等即时补充不会倒扣回去。结束使用时请正常关闭程序，以便完成原值恢复；强制结束进程无法执行退出清理。

## 作用范围

钩锁距离功能仍需瞄准可抓取、已经加载的实体，并符合游戏的命中判定。不会穿墙，也不会主动加载远方地图。本次实际完成了约 **184 米**外目标的命中与牵引；100 km 是设置后的参数上限，并未声称全程测试到这一距离。

玩家速度同时影响动作、移动以及角色相关计时。跳跃高度设置的是起跳速度，并非以米为单位的最终高度；实际高度也受重力影响。

无限跳跃优先于自定义跳跃次数，关闭后使用已应用的自定义次数。无限生命开启时，需要先关闭它再执行低生命值；无限法力与法力不足同理。

无限弹药跟随当前装备的枪械，切枪后自动补充。一次性“设置弹药”只作用于当前枪械。游戏部分 HUD 使用事件刷新，直接设置后的数字可能要到下一次射击或相关事件才更新；概览页读取当前游戏数值。

程序用于本机单人游戏。检测到其他玩家或网络连接后暂停修改；本次没有进入多人房间进行实测。

## 配置与文件

“窗口置顶”在左下角。可在 F1 说明中更改游戏目录。输入的数值与目录保存在 `%LOCALAPPDATA%\EchoPointNovaTrainer\settings.txt`，开关状态不会保存，每次启动均关闭。

程序只修改运行中游戏的内存，不改写游戏安装文件。退出游戏会自然清除运行中的修改；游玩时游戏本身仍可能自动保存生命、弹药等状态。

公开仓库包含测试报告、界面预览和构建源码；EXE 与校验文件通过 GitHub Release 提供。个人存档与开发时的本地备份不公开上传。
